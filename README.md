# Sree Lamination Quotes

The “Get a Quote” button should scroll/navigate to the enquiry form.

Customers should be able to select:

- Gloss
- Matt
- Gold
- 3D
- Custom

Do not display fixed prices unless I provide them.

Technical Requirements

Use:

- React
- Vite
- Tailwind CSS
- Supabase
- Modern component-based architecture
- Responsive design
- Proper form validation
- Loading states
- Error handling
- Success notifications

Make sure the project can be deployed to Netlify.

Create a proper production-ready structure.

Use environment variables for Supabase credentials.

Do NOT expose secret keys in frontend source code.

SEO

Add:
Title:
“Sree Lamination | Gloss, Matt, Gold & 3D Lamination Services”

Meta description:
“Sree Lamination provides professional Gloss, Matt, Gold and 3D sheet lamination services with quality finishing and reliable service.”

Add proper headings, alt text and basic SEO.

Important

Do not invent:

- Phone number
- Address
- Email
- Prices
- Business history
- Reviews
- Awards
- Certifications

Use clearly marked placeholders for these details so I can replace them later.

Make the final website visually impressive, professional, fast, mobile-friendly and easy for a local customer to use.
